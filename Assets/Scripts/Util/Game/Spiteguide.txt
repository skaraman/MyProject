SpriteWithNormals Memory-Safe Dynamic Loading Plan

Goal
- Prevent memory overflow/crashes by loading only the sprite slices needed right now.
- Never keep thousands of unused sprites/textures resident in GPU or RAM memory.

GameObject SpriteWithNormals color sprite and normal sprite will use one sprite and one normal 

Relationships exist in SpriteLibraries but these should not be used since they are terrible and load 
all sprites, instead these are only used because I spent hours of my time putting in the relationships of the 
gear part name, form, animation and sprite slice, so we don't use these as sprite libarary assets, we use them as
text assets and pull out the relationships, 

forget using sprite libararies as a library just read it as text, instead create a ad hoc approach to load in each sprite slice per the relationships
name (formally sprite libarary name) - form (formally label) - animation (formally category) - sprite (formally sprite ref in label)

Do not try to solve everything through code, somethings will require action in the Unity Editor, specify these steps in an output file next to this guide.
